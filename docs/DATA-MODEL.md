# SpaceGuard AI — Data Model

## Satellite

Source: `backend/src/data/demoSatellites.js`

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique identifier (e.g., `sat-25544`) |
| `name` | string | Display name (e.g., `ISS (ZARYA)`) |
| `noradId` | number | NORAD catalog ID |
| `lat` | number | Latitude (degrees) |
| `lng` | number | Longitude (degrees) |
| `altitude` | number | Orbital altitude (km) |
| `velocity` | number | Orbital velocity (km/s) |
| `orbitalPeriod` | number | Orbital period (minutes) |
| `inclination` | number | Orbital inclination (degrees) |
| `lastUpdate` | string (ISO-8601) | Timestamp of last telemetry |
| `dataSource` | string | `DEMO` or future live source |
| `type` | string | Orbit type: `LEO`, `MEO`, `GEO` |
| `description` | string | Human-readable description |

## Health Assessment

Generated by: `backend/src/services/healthService.js`

| Field | Type | Values |
|-------|------|--------|
| `satelliteId` | string | References `Satellite.id` |
| `status` | enum | `HEALTHY`, `WARNING`, `DEGRADED`, `CRITICAL` |
| `riskLevel` | enum | `LOW`, `MEDIUM`, `HIGH`, `CRITICAL` |
| `issues` | string[] | List of detected issue descriptions |
| `explanation` | string | Human-readable assessment narrative |
| `recommendedAction` | string | Suggested operator action |

### Health Evaluation Rules

1. **Data age** — hours since `lastUpdate`: >2h=WARNING, >6h=DEGRADED, >24h=CRITICAL
2. **Altitude deviation** — compared to expected range for orbit type
3. **Velocity anomaly** — compared to expected velocity for altitude
4. **Space weather** — Kp >5=WARNING, >7=CRITICAL
5. **Status derivation** — worst individual check determines overall status

## Anomaly

Generated by: `backend/src/services/anomalyService.js`

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique ID (e.g., `anomaly-1693497600000-1`) |
| `satelliteId` | string | References `Satellite.id` |
| `satelliteName` | string | Satellite display name |
| `type` | enum | `STALE_DATA`, `ALTITUDE_DEVIATION`, `VELOCITY_ANOMALY`, `SPACE_WEATHER_ALERT`, `MISSING_TELEMETRY` |
| `severity` | enum | `LOW`, `MEDIUM`, `HIGH`, `CRITICAL` |
| `condition` | string | Short condition description |
| `explanation` | string | Detailed explanation |
| `recommendedAction` | string | Suggested response |
| `detectedAt` | string (ISO-8601) | Detection timestamp |

## Alert

Generated by: `backend/src/services/alertService.js`

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | `alert-{anomalyId}` or `alert-sw-{timestamp}` |
| `satelliteId` | string\|null | null for fleet-wide alerts |
| `satelliteName` | string | Satellite name or `Fleet-wide` |
| `type` | string | Anomaly type or `SPACE_WEATHER` |
| `severity` | enum | `LOW`, `MEDIUM`, `HIGH`, `CRITICAL` |
| `title` | string | Human-readable alert title |
| `message` | string | Alert condition |
| `explanation` | string | Detailed explanation |
| `recommendedAction` | string | Suggested response |
| `createdAt` | string (ISO-8601) | Alert creation timestamp |
| `acknowledged` | boolean | Always `false` (no persistence) |

## Space Weather

Source: `backend/src/services/spaceWeatherService.js`

| Field | Type | Description |
|-------|------|-------------|
| `kpIndex` | number | Geomagnetic Kp index (0-9) |
| `solarWindSpeed` | number | Solar wind speed (km/s) |
| `solarWindDensity` | number | Solar wind density (protons/cm³) |
| `xrayFlux` | number | X-ray flux (W/m²) |
| `geomagneticStorm` | boolean | true if Kp ≥ 5 |
| `alertLevel` | enum | `GREEN`, `YELLOW`, `ORANGE`, `RED` |
| `lastUpdate` | string (ISO-8601) | Data timestamp |
| `source` | string | `NOAA` or `DEMO` |
